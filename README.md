# Recycling Kiosk System

## Overview
This project is a smart recycling kiosk designed to provide an accessible and environmentally friendly way for people to recycle waste. The system allows users to easily tag and drop off recyclable items while earning reward points.

The kiosks are designed to be distributed across locations such as Makers Valley to promote sustainable recycling practices.

---

## How It Works
1. Print a recycling tag  
2. Attach the tag to the bag containing the item  
3. Drop the item into the kiosk hatch  

---

## Features
- User-friendly recycling process  
- Tagging system for waste tracking  
- Reward points system based on recycled items  
- Integration with external platform for tracking progress  
- Redeemable points for items in participating shops  

---

## Purpose
The goal of this project is to:
- Encourage environmentally friendly behaviour  
- Make recycling accessible to everyone  
- Incentivise users through a rewards system
